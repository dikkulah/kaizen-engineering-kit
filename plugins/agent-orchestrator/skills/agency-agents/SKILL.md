# Agency Agents Skill (`agency-agents`)

Zero-token-bloat lazy router indexing 220+ specialist personas across 18 divisions (Engineering, Security, Testing, Product, Architecture, etc.).
Specialists are loaded dynamically on demand, keeping system prompt overhead at 0 tokens until invoked.

Run via CLI:
```bash
kaizen-kit adk list
```
